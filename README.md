# Калькулятор кредита

Простой offline-калькулятор аннуитетного кредита на HTML + CSS + JS. Один файл `index.html` — без зависимостей, можно открыть прямо в браузере (и на телефоне).

## Возможности

- Расчёт ежемесячного (аннуитетного) платежа по сумме кредита, первоначальному взносу, ставке и сроку.
- Срок задаётся в годах, расчёт ведётся помесячно.
- Добавление произвольного числа **досрочных погашений** с выбором стратегии:
  - **Уменьшить срок** — платёж остаётся прежним, сокращается число месяцев.
  - **Уменьшить платёж** — срок остаётся прежним, пересчитывается платёж.
  - Для каждого досрочного погашения месяц задаётся отдельно (1 = первый платёж, можно указать любой месяц, например 6-й).
- Любое изменение параметров пересчитывает весь расчёт **живьём** — прямо по мере ввода.
- Числа отображаются группами по 3 цифры с пробелом (`1 200 000`) — и в результатах, и в полях ввода (форматирование на лету по мере набора).
- Показывается **процент первоначального взноса** от полной стоимости; если он меньше 20,1% (константа `MIN_DOWN_PCT`), поле подсвечивается красным.
- Помесячный график платежей с разбивкой на **тело кредита** и **проценты**.
- Полная таблица платежей: номер месяца, платёж, тело, проценты, досрочное погашение, остаток долга; строки с досрочными погашениями подсвечены.

## Как использовать

1. Откройте `index.html` в браузере (просто двойной клик).
2. Заполните параметры:
| Поле | Описание |
| --- | --- |
| Стоимость/сумма кредита | полная стоимость покупки |
| Первоначальный взнос | собственные средства (вычитаются из суммы); под полем показывается доля от стоимости, при < 20,1% поле подсвечивается красным |
| Процентная ставка | годовая ставка, % |
| Срок | срок кредита в годах |

Числа в полях можно вводить с пробелами и запятой в качестве десятичного разделителя (`18,5` = 18.5); по мере набора значение форматируется группами по 3 цифры.
3. При необходимости добавьте досрочные погашения: укажите **номер месяца от начала кредита** (1 = первый платёж), сумму и стратегию.
4. Результаты появятся автоматически: итоги, график и помесячная таблица.

## Что показывают итоговые карточки

- Стоимость
- Первоначальный взнос (с процентом от стоимости)
- Сумма кредита (стоимость − взнос)
- Ежемесячный платёж
- Срок платежей (в годах и месяцах — видно сокращение после досрочных погашений)
- Переплата (сумма процентов)
- Выплачено тела кредита (включая досрочные погашения)
- Итого выплат (тело + проценты)

## Формулы

Аннуитетный платёж (месячная ставка `r = ставка% / 100 / 12`, срок `n` месяцев, тело кредита `P`):

```
payment = P * r * (1+r)^n / ((1+r)^n - 1)
```

При `r = 0` используется равномерное деление: `payment = P / n`.

Разбивка каждого платежа по месяцам:

```
проценты = остаток * r
тело     = платёж - проценты
остаток  = остаток - тело
```

Последний платёж корректируется, если остаток меньше очередного платежа.

Досрочное погашение суммы `E` в месяце `m`:

- сначала списывается обычный процент `остаток * r` и тело;
- тело кредита дополнительно уменьшается на `E` (но не ниже нуля);
- **уменьшить срок** — срок пересчитывается из уравнения аннуитета при том же платеже, число месяцев сокращается;
- **уменьшить платёж** — платеж пересчитывается за оставшиеся месяцы: `payment′ = annuity(остаток, r, n − m)`.

Минимальный предел платежа при стремлении срока к бесконечности — сумма «только процентов»: `P * r`. Поэтому при высоких ставках разница в платеже между длинными сроками (например 15 и 20 лет) мала, а переплата сильно растёт.

В строке таблицы за месяц с досрочным погашением сохраняется **фактически уплаченная** в этом месяце сумма (аннуитет), а не пересчитанный платёж, действующий со следующего месяца.

Доля первоначального взноса:

```
pct = первоначальный взнос / стоимость * 100
```

Если `pct < 20.1` (константа `MIN_DOWN_PCT`), поле ввода подсвечивается красным, а подсказка под полем показывает предупреждение.

## Структура кода

Всё содержится в одном файле:

- `buildSchedule(principal, annualRate, months, early)` — основной расчёт, возвращает массив строк платежей и итоги;
- `annuityPayment(P, r, n)` — аннуитетная формула;
- `calc()` — чтение полей, вызов расчёта, отрисовка итогов (в т.ч. процент взноса и подсветка поля);
- `renderChart()` — график «тело vs проценты» по месяцам;
- `renderTable()` — помесячная таблица;
- `renderEarlyList()` — список досрочных погашений;
- `fmt(n)` / `fmtPct(n)` — форматирование чисел (группы по 3 цифры с неразрывным пробелом) и процентов (0,1%);
- `parseNum(s)` / `fmtInputVal(s)` — разбор введённых значений (пробелы, запятая) и живое форматирование полей ввода;
- `MIN_DOWN_PCT` — порог доли первоначального взноса (20,1%), ниже которого поле подсвечивается красным.

Расчёт отделён от интерфейса, поэтому `buildSchedule` легко переиспользовать или покрыть тестами.

## Тестирование

Логику можно проверять без браузера, вытащив чистые функции `annuityPayment` и `buildSchedule` из `<script>`:

```js
eval(srcFromHtml); // чистые функции: annuityPayment, buildSchedule, fmt, parseNum, ...
buildSchedule(1200000, 18, 60, [{ month: 12, amount: 100000, type: "term" }]);
// => 54 мес., платёж 30 472 ₽, переплата 532 215 ₽

// платёж не в первый месяц, а в 6-й — переплата зависит от момента:
buildSchedule(1200000, 18, 60, []);                                    // переплата 628 327 ₽
buildSchedule(1200000, 18, 60, [{ month: 1,  amount: 100000, type: "term" }]); // 499 196 ₽
buildSchedule(1200000, 18, 60, [{ month: 6,  amount: 100000, type: "term" }]); // 514 756 ₽
buildSchedule(1200000, 18, 60, [{ month: 12, amount: 100000, type: "term" }]); // 532 215 ₽
```
